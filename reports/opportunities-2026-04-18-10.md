- **MCP is underserved**: Very few freelancers list MCP-specific skills. A Fiverr gig titled "I'll build a custom MCP server for Claude" has near-zero competition right now (April 2026).
- **n8n + Claude combo**: The most-requested stack on Upwork this month. Build 2–3 templates and reuse them.
- **Profile differentiation**: Mention Claude Code CLI expertise explicitly — most competitors only list "Claude API". Claude Code knowledge signals production-grade tooling.
- **Price anchoring**: List a $50 basic tier + $300 standard + $500 premium on Fiverr. Clients self-select; the premium tier drives 60%+ of revenue.
