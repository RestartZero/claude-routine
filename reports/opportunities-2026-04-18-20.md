## STRATEGIC NOTES

1. **Claude Code is the moat.** Most developers use OpenAI or generic LangChain. Positioning explicitly as a "Claude Code specialist" targets a smaller but less saturated market where Anthropic's own momentum works in your favor.

2. **MCP is the new API integration.** The MCP ecosystem is exploding with thousands of servers. Offering MCP-related services (build, audit, setup) is like offering "REST API integration" in 2015 — foundational and endlessly repeatable.

3. **Routines = immediate consulting opportunity.** Anthropic launched Claude Code Routines on Apr 14, 2026. Almost no freelancers have hands-on experience yet. Writing a tutorial or Upwork profile featuring this within the week captures first-mover search traffic.

4. **Chinese dev advantage:** n8n + Make.com automation is heavily used by non-English-speaking SMBs in Asia-Pacific — consider listing on Chinese platforms (e.g., 猪八戒, Freelancer.cn) with the same skill set for less competition.
